## Overview

Podium is a concept learning management system designed around one observation: most LMS interfaces bury the two things people actually need — *what is due* and *what to grade next*. This sample case study demonstrates how I approach product design and full-stack development together.

## The Problem

Course administrators juggle spreadsheets, email threads and clunky dashboards. Tutors lose time navigating menus instead of teaching, and students miss deadlines because critical information sits three clicks deep.

## The Approach

I started by mapping the daily routine of a single tutor and a single student, then designed every screen around those two journeys. Wireframes were tested as static prototypes before a line of application code was written.

## The Solution

The interface leads with a prioritised action feed: upcoming deadlines, ungraded submissions and unread questions surface first. A calm neutral palette keeps attention on content, with a single accent colour reserved for actions that move work forward.

## Under the Hood

The front end is componentised React with strict TypeScript. The API layer separates read and write concerns so dashboards stay fast under load. Accessibility was treated as a requirement, not a feature — keyboard flows cover every core task.
